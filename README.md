# Ustaad Mechanic - 3D Unscrew Puzzle Game

An interactive, desi garage-themed 3D unscrew puzzle game built with Three.js and Cannon-es physics.

## Features
- **3D Physics-driven gameplay**: Unscrew bolts and let plates drop realistically with gravity.
- **Desi Garage Aesthetic**: Authentic workshop vibes with wrench tools, rust effects, and sound feedback.
- **Multiple Challenge Levels**: Puzzles with intersecting plates, trapped nuts, and screw holes.
- **Touch & Mouse Friendly**: Optimized for both desktop and mobile web browsers.

## Tech Stack
- [Three.js](https://threejs.org/) (WebGL 3D Rendering)
- [Cannon-es](https://github.com/pmndrs/cannon-es) (Rigid-body 3D Physics engine)
- HTML5, CSS3, ES6 JavaScript Modules

## How to Play
1. Clone the repository or open `index.html` in a web browser (via local web server or GitHub Pages).
2. Tap or click on screws to unscrew them into an open hole or collector.
3. Drop all plates to clear each workshop job level!
